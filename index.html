    > Firewall_Learning_Center

    Tipe-Tipe Firewall

    • Packet Filtering: Memeriksa IP dan Port pada header paket secara individu tanpa melihat status koneksi. (Cepat tapi kurang pintar).
    • Stateful Inspection: Melacak status koneksi aktif (established, new) sehingga lebih aman dan mencegah intrusi manipulasi paket.
    • Proxy Firewall: Menjadi perantara antara klien dan server, menyembunyikan identitas asli klien internal.
    • Next-Gen Firewall (NGFW): Menggabungkan firewall tradisional dengan IPS/IDS, Antivirus, dan Deep Packet Inspection (DPI).

    Arsitektur DMZ

    Demilitarized Zone (DMZ) adalah subnetwork yang mengekspos layanan publik (seperti Web Server, Mail Server) ke internet (WAN).

    Tujuannya agar jika server di DMZ diretas, LAN internal perusahaan tetap aman di balik lapis firewall sekunder.
